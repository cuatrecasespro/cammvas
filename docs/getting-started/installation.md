# Installation

{% stepper %}
{% step %}
### Open community plugins

Go to **Settings** > **Community plugins** > **Browse**.
{% endstep %}

{% step %}
### Search for Cammvas

Type "Cammvas" in the search bar and click **Install**.
{% endstep %}

{% step %}
### Enable the plugin

Toggle Cammvas on in the **Installed plugins** list.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Cammvas requires Obsidian v1.13.4 or later.
{% endhint %}
